# Charity Hospital Reporting source

Charity Hospital Reporting was prepared by Eric Gonzalez-Payne with AI-assisted development for charity-hospital administration.

This release contains the application, documented third-party components and synthetic tests. Hosting and AI configuration are inactive until an operator deliberately configures a separate environment.

The repository begins with this reviewed source snapshot. It does not reconstruct earlier development history and should not be presented as satisfying a program that requires that history.

The MIT license covers the author’s original application code and documentation. Third-party dependencies and OCR models remain under their respective licenses.
